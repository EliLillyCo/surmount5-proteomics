# Contributing

Thank you for your interest in the SURMOUNT-5 proteomics analysis code.

## Scope

This repository is a paper companion containing the analysis code underlying
the manuscript results. It is not a general-purpose library and is not actively
accepting feature contributions.

## Bug reports and questions

If you encounter issues reproducing the analysis or have questions about the
methodology, please open a
[GitHub Issue](https://github.com/EliLillyCo/surmount5-proteomics/issues).

## Reporting security vulnerabilities

If you discover a security vulnerability, please report it responsibly via
[GitHub Security Advisories](https://github.com/EliLillyCo/surmount5-proteomics/security/advisories)
rather than opening a public issue.

## License

By submitting a contribution (pull request, issue, or comment), you agree that
your contribution is licensed under the same [MIT License](LICENSE) that covers
this project.

## Code of conduct

We expect all interactions to be respectful and constructive. Harassment,
discriminatory language, and bad-faith engagement are not tolerated.
